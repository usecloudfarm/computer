GitHub as an app plugin.

Code hosting. Read and open issues, comment on them, list pull requests and commits, and search issues across GitHub.

Generated from `tools/integration-codegen/specs/github.mjs` — the spec is the
source of truth, and `pnpm gen:integrations:check` fails if the committed
package has drifted from it.
