```bash
pnpm install
pnpm dev            # the playground: http://localhost:5173
pnpm build
pnpm test           # node
pnpm test:workers   # workerd
pnpm check          # format, lint, typecheck, build, both suites
```

`pnpm check` is the gate. Run it before every commit; it is what CI runs.

## Layout

```text
packages/
  core/                  @cloudfarm/computer
  sandboxes/             the shell
  engines/               code mode
  storage/               where files live
  toolsets/              agent framework adapters
  integrations/          apps
apps/
  web/                   the playground
  docs/                  this site
```

The folder a package sits in declares which interface it implements. See
`.claude/skills/cloudfarm-structure/SKILL.md` before adding one.

## The docs site

```bash
pnpm --filter @cloudfarm/docs dev
pnpm --filter @cloudfarm/docs build
```

Pages are Markdown under `apps/docs/src/content/docs/`. The sidebar is
declared in `astro.config.mjs`; `reference/` is autogenerated from its
folder, ordered by each page's `sidebar.order`.
